# 公务员考试备考计划（6个月版）

## 📅 整体时间规划

| 阶段     | 时间跨度  | 核心目标                     |
| -------- | --------- | ---------------------------- |
| 基础夯实 | 第1-2个月 | 系统学习知识点，建立知识框架 |
| 专项突破 | 第3-4个月 | 分模块强化训练，提升正确率   |
| 真题冲刺 | 第5个月   | 全真模拟考试，掌握命题规律   |
| 考前调整 | 第6个月   | 查漏补缺，调整应试状态       |

## 📚 每日学习安排（参考模板）

```text
🕗 08:00-08:30  晨读（时政热点/申论范文）
🕘 09:00-11:30  行测模块训练（如：资料分析+判断推理）
🕛 12:00-14:00  午休（含30分钟新闻联播回放）
🕑 14:00-17:00  申论写作练习（含范文批改）
🕔 17:00-18:00  错题整理与知识点复盘
🕖 19:30-21:30  专项突破（当日薄弱环节）
🕙 21:30-22:00  时政速记（学习强国APP）
```

## 🎯 各科目重点突破

### 行测（占比60%）

    title 行测时间分配建议
    "常识判断" : 10
    "言语理解" : 25
    "数量关系" : 15
    "判断推理" : 30
    "资料分析" : 20

### 申论（占比40%）

🗓 每周计划：

- 精读3篇人民时评（标注金句）
- 完成2套真题写作（大作文+小题）
- 整理1套规范表达模板（如：乡村振兴类）

3. **文具类**：

## ❗ 常见误区警示

```diff
- 错误做法：盲目刷题不复盘
+ 正确做法：每题记录错误类型（如：计算错误/知识点盲区）

- 错误做法：只做擅长模块
+ 正确做法：每周固定时间突破短板（如：周一专攻数量关系）

- 错误做法：申论只看不写
+ 正确做法：手写答题卡保持卷面工整
```
